くじ引きサイト 試作品 2026-10
===========================================
【決定した仕様】
運用：Cloudflare Pages 無料プランの静的Webサイト
参加者：各自のスマホの4G/5G/Wi-FiでQRコードからアクセス
初回通信：必要／初回の画像を含めた読込が完了すれば以降オフラインでも利用可能
参加回数：無制限（参加者ID・履歴・個別QRなし）

【スマホ】
1. 最初に「ひりつき」か「ノーマル」を選択
2. 3秒間、該当コースの結果画像を高速で切り替え
3. 抽選結果画像で停止
4. 画面をタップすると同じコースで再抽選
5. 左上の「‹」で選択画面へ戻る（抽選終了後のみ）

【PC】
Z：ひりつき／X：ノーマル／F：全画面の切り替え（Escで解除）
PCでは以前同様、最初から左「当たり」の結果画像が表示されます。

【確率（毎回独立抽選）】
ひりつき：大当たり5％、当たり90％、はずれ5％
ノーマル：大当たり10％、当たり90％
抽選中は入力されません（3秒間）。ロック最低2秒も設定済み。

【画像】
同じフォルダに次の5画像を置いてください。
 ooatari.png          ひりつき 大当たり
 atari.png            ひりつき 当たり
 hazure.png           ひりつき はずれ
 migi_ooatari.png     ノーマル 大当たり
 migi_atari.png       ノーマル 当たり
※添付画像は動作確認用の仮画像です。同じファイル名で上書きしてください。
※各画像は画面内に収まるように全体表示されます（object-fit: contain）。

【公開方法：Cloudflare Pages（公式マニュアル）】
https://developers.cloudflare.com/pages/get-started/direct-upload/
1. https://dash.cloudflare.com/ でCloudflareの無料アカウントを準備
2. Workers & Pages -> Create application -> Get started -> Drag and drop your files
3. このフォルダ内の index.html, sw.js, PNG 5枚を含むフォルダ又はZIPをアップロード
4. サイト名を設定して Deploy site
5. 発行された https://(サイト名).pages.dev/ にスマホからアクセス
6. このURLをQRコード化し、掲示する
※まだ公開していないため、このZIPにはイベント本番のQRコードを含みません。

【画像を差し替えて再公開する場合】
1. PNG5枚を同じ名前で上書き
2. sw.js の const VERSION = "lottery-cache-v1"; を lottery-cache-v2 などに変更
3. 新しいフォルダ／ZIPをCloudflare Pagesに再アップロード
4. スマホはページを再読み込み。古い画像が出る場合は再読み込みやサイトデータの削除

【オフライン動作の注意】
インターネット公開サイトへの初回アクセスには通信が必要です。
HTTPS公開時にService Workerが起動し、HTMLと結果画像5枚をスマホへ保存します。
ブラウザ側がキャッシュを削除した場合は再度通信が必要です。
利用端末やブラウザによっては、初回に読み込んだ直後より、再読み込み後の方が確実です。

【景品交換に使う場合の注意】
参加回数に制限がなく、結果はスマホ内で決定されます。
再抽選やブラウザ操作による改変ができるため、景品を厳密に管理する用途には不向きです。
本番の景品交換はスタッフが別途ルールを設定してください。
